# /phase — 현재 개발 단계 확인

PROJECT_PLAN.md를 읽어 현재 완료된 Phase와 다음 할 일을 정리합니다.

## 실행할 작업

1. `PROJECT_PLAN.md`의 체크리스트(`- [ ]` / `- [x]`) 항목을 모두 읽습니다.
2. 완료된 항목과 미완료 항목을 Phase별로 분류합니다.
3. 현재 진행 중인 Phase와 다음 우선순위 작업을 표로 출력합니다.
4. `CLAUDE.md`의 "현재 개발 단계" 표와 일치하는지 확인합니다.

## 출력 형식

```
현재 단계: Phase N — <Phase명>
완료: X개 / 전체: Y개

[다음 할 일 Top 3]
1. ...
2. ...
3. ...
```
